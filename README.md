# OWASP-Juice-shop-API-automation

A complete project designed and developed from scratch to validate and automate the OWASP Juice Shop APIs.

## 📌 Project Overview

This project is built for validating and verifying the functionality of Juice Shop APIs, adhering to the best practices of modern API automation frameworks using the latest industry tools and technologies. 

A robust and solid architecture was built from the ground up to enhance and ensure scalability, maintainability, and security.

---
## 🎯 Key Goals & Achievements

Here are the key goals that have already been successfully reached and achieved in this project:

1. **Solid & Clear Architecture:** Separation of concerns with multiple organized packages classified by feature, maximizing scalability and readability.
2. **High Maintainability:** Built with a forward-thinking mindset—because anyone can write a script, but great engineers design for tomorrow. The **DRY (Don't Repeat Yourself)** principle is strictly applied throughout.
3. **Readability:** The project structure is clean and intuitive. Even non-technical stakeholders can easily grasp the project's purpose, business requirements, and backend mechanics.
4. **Security:** Sensitive information and credentials (such as user emails, passwords, and tokens) are kept safe and properly managed.
5. **Performance & Quality:** Performance and reliability were prioritized right from the start, even before writing a single line of code.
